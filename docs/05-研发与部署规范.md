### 7.3 Graph Job 租约恢复

- 每次 worker claim 都有唯一 fencing token；heartbeat 只能续租当前 token，旧 owner 不得完成落账。
- 普通 Job 的 stale lock 可按现有策略自动恢复。`graph_start` / `graph_resume` 的 stale lock 表示旧 Graph 调用是否仍存活未知，必须 fail-closed 到 `needs_manual_review`，不得直接自动重放。
- 管理员应先在编排/容器平台确认旧 worker 进程或 Pod 已终止，再调用 `POST /api/v1/jobs/{job_id}/retry-stale-graph`，请求体必须设置 `confirm_previous_worker_stopped=true`，并填写不含客户敏感信息的恢复原因。
- 未确认旧 worker 已停止时接口返回 409。恢复操作会复用原 Job 与 execution/thread identity，不创建新的业务请求；确认人、时间和脱敏原因保留审计。
- 目标环境必须演练 heartbeat 正常续租、进程强杀、stale fail-closed、管理员确认恢复，以及 Resume 后已成功副作用不重复。
- 自动化入口为 `tests/test_job_lease_integration_mysql.py`，同时要求 `DB_SMOKE_DATABASE_URL` 指向 localhost `repair_system_test` 且 `RUN_JOB_LEASE_INTEGRATION_TESTS=1`；发布流水线也可直接运行 `python -m tools.audit_langgraph_release --probe-local-test-job-lease` 获取结构化结果。测试库存在其他 queued/retry_wait/running Job 时会拒绝执行，避免领取真实测试任务。
- 同邮件派发并发入口为 `tests/test_email_dispatch_integration_mysql.py`，必须显式设置 `RUN_EMAIL_DISPATCH_INTEGRATION_TESTS=1`，且只能在没有后台 worker 的独立 localhost `repair_system_test` 执行。测试会写入一封 `example.invalid` 合成邮件，并在首事务内把合成 `graph_start.next_run_at` 设置到未来，避免被轮询器领取；随后验证第二个 Session 在首事务提交前阻塞，提交后复用相同 execution/job。探针还会把合成 Job/execution 置为 failed，验证真实恢复 Service 只复活原 Job 并保持 execution 绑定，最后按外键顺序精确清理。
- 发布审计 schema v2 的 `audit_passed`/`requested_checks_passed` 只表示本次请求的检查通过；只有 Graph 模式且 checkpoint、Job lease、同邮件并发派发三个本地测试探针均执行通过时，`local_graph_release_gate_passed` 才为 true。工具始终将 `production_signoff_complete` 设为 false，因为真实 SAP/SMTP/OSS、金标、业务签收和灰度结果不能由配置探针替代；消费方不得继续按 schema v1 的两探针语义判定 gate。
- Graph 部署还要求预发布证据的来源工作树为 clean、`source.commit` 与服务器 `git rev-parse HEAD` 完全一致、JSON 的 SHA-256 sidecar 匹配，且采集时间不早于部署前 168 小时、不得明显晚于当前时间。`release-evidence/` 只读挂载到容器 `/app/release-evidence`，解析后的 JSON/sidecar 路径必须仍位于该可信根；证据校验发生在 PostgreSQL checkpoint 初始化之前，缺失、篡改、旧 commit、dirty 来源、过期/未来时间、目录逃逸、旧 schema、探针不完整或 gate=false 均终止部署。
- 该门禁不仅存在于 `deploy.sh`：FastAPI lifespan 会在读取 runtime config、初始化 RMA、创建 scheduler/内置 Job worker 之前再次验证同一证据。任何直接 `docker compose up`、Kubernetes 或其他启动方式都必须注入 `APP_RELEASE_COMMIT` 与证据配置，否则 Graph 模式进程启动失败。管理员 `/api/v1/system/runtime-status` 返回当前进程启动时固化的 `langgraph_release_gate` 摘要；不在请求时重新读取可轮换文件。
