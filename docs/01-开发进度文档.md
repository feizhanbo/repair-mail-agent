## 6. 业务闭环

当前闭环能力：

1. **IMAP 自动入库** — APScheduler 每 5 分钟拉取 `rmatest1@accotest.com`，自动去重（`message_id` UNIQUE约束）、归并（In-Reply-To / 归一化主题 / 新线程）、解析。
2. **双 Provider AI 解析** — DeepSeek（`chat_json` 文本对话）+ Qwen（`chat_json` 文本 + `vl_chat` 多模态），规则预解析 → AI 最终解析 → 置信度评估 → 自动应用 / 转人工复核。
3. **附件多模态注入** — PDF/图片附件先上传 OSS → Qwen VL 提取结构化信息 → 结果注入 AI 解析流水线 `multimodal_results` 字段。
4. **工单生成与 SN 校验** — 高置信 AI 结果自动建单 → SN 校验（查询 `sn_assets` → 客户匹配 / 物料匹配 / 北京发货）→ 校验失败通知 supervisor。
5. **自动追问 ≤3 轮** — `need_customer_info` 工单按模板 + AI 润色生成追问草稿 → SMTP 白名单检查 → 自动发送（`auto_send_enabled=true`）或人工审核后发送。
6. **客户确认到货闭环** — 客户回复"收到/已收到/到货" → `customer_receipt_confirmed` 意图识别 → `ready_for_export → closed` 自动关单。
7. **人工复核兜底** — 低置信、字段冲突、SN 异常、追问超限、AI 不可用等场景统一进入人工复核任务池，支持领取/分配/处理/重解析。
8. **OSS 全量归档** — 手工入库、EML 上传、IMAP 拉取的原始 EML 和附件二进制，在入库时同步上传 OSS。
9. **SMTP 三层白名单** — `SMTP_RECIPIENT_WHITELIST` 为空阻止所有外发；自动发送硬检查白名单；SMTP 发送入口二次校验。开发阶段只允许向白名单内测试邮箱发信。

## 7. 工单状态流转

| 状态码 | 中文 | 类别 | 终态 |
|--------|------|------|------|
| `new_email` | 邮件已入库 | intake | - |
| `parsed` | 已解析 | processing | - |
| `need_customer_info` | 待客户补充 | waiting | - |
| `auto_replied` | 已自动回复 | waiting | - |
| `manual_review` | 人工复核 | review | - |
| `ready_for_export` | 可导出 | export | - |
| `error` | 异常 | error | - |
| `closed` | 已关闭 | terminal | **是** |

**核心流转路径：**

```
邮件入库 → reparse_email / IMAP 拉取
  ├─ AI 高置信 → new_email → parsed → [need_customer_info → auto_replied → (客户回复) → parsed]
  │                                      → [ready_for_export → (客户确认到货) → closed]
  ├─ AI 低置信 → new_email → manual_review → (人工 resolve) → ready_for_export / need_customer_info / closed
  ├─ AI 需人工 → manual_review（直接）→ (人工 resolve) → ...
  └─ AI 不可用 → manual_review（规则解析候选）→ (人工 resolve) → ...
```

**13 条基础转换规则**（含 `customer_receipt_confirmed` 自动关单）：

| # | from → to | trigger_event | 条件 |
|---|-----------|--------------|------|
| 1 | new_email → parsed | parse_completed | 置信度 ≥ 阈值 |
| 2 | new_email → manual_review | parse_low_confidence | 置信度 < 阈值 |
| 3 | parsed → ready_for_export | validation_passed | 字段完整 + SN 校验通过 |
| 4 | parsed → need_customer_info | missing_fields_detected | 关键字段缺失 |
| 5 | parsed → manual_review | field_conflict | 字段冲突 / SN 异常 |
| 6 | need_customer_info → auto_replied | reply_draft_created | 追问草稿已生成 |
| 7 | auto_replied → parsed | customer_reply_received | 客户回复补充信息 |
| 8 | manual_review → ready_for_export | manual_resolved | 人工修正 + 校验通过 |
| 9 | manual_review → parsed | manual_resolved | 人工修正回解析态 |
| 10 | manual_review → need_customer_info | manual_resolved | 人工判定需客户补充 |
| 11 | error → parsed | manual_resolved | 异常修复 |
| 12 | ready_for_export → closed | export_completed | 导出/下游同步完成 |
| 13 | ready_for_export → closed | **customer_receipt_confirmed** | **客户确认到货自动关单** |
