## 当前业务链路

`new_email → parsed → need_customer_info → auto_replied → parsed → ready_for_export → closed`

- `parsed → need_customer_info`：仅客户必填字段缺失。
- `need_customer_info → auto_replied`：缺失字段追问实际发送成功。
- `parsed → ready_for_export`：SN 核心校验和完整安全闸门均通过。
- `ready_for_export → closed`：公司已收货、RMA 已实际发送，且收货确认回复实际发送成功。
- 低置信、冲突、附件失败、主数据问题和系统错误仍可进入人工复核，但人工任务不得替代业务状态事实。
